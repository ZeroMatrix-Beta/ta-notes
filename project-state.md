# project-state.md — DEPRECATED

⚠️ **Deprecated 2026-08-10 on the user's instruction. Do not write to this file, and do not
recreate what it held.**

It used to record how far the project had got. That was a mistake: the status went stale faster
than anyone re-read it, and a stale status line is worse than none, because it gets believed. It
had also accumulated rules that belonged in the other three files, where they were then
contradicted.

**There is now no file for project status.** `git log` is the record of what has been done, and it
does not rot. If you find yourself wanting to write down how far something has got, don't — say it
in your reply to the user.

Everything worth keeping was moved out on 2026-08-10:

| What it held | Where it lives now |
|---|---|
| Blueprint tutor, merging by topic, the source folders, the reference documents, scope against the lecture notes, errors in the script, `git add -A` | `gemini.md` |
| Exercise transcription conventions, German mirroring, provenance rules | `style.md` |
| Document layout, file naming, heading suffixes, `main.pdf` is tracked | `build-and-preamble.md` |
