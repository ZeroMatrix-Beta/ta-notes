\chapter{Completeness and the Banach Fixed Point Theorem}
\label{ch:completeness}

% Transition: Claude Opus 5 (Medium)
Having examined how maps behave between metric spaces, we return to a property of a single space:
whether every sequence that \qt{looks like} it should converge
(\cref{def:convergent_sequence}) actually does. Completeness is the first genuinely \emph{metric}
rather than topological property in this part --- two metrics can have exactly the same open sets
while only one of them is complete --- and the Banach fixed point theorem is what it is usually
good for.
