# Analysis II — TA notes

Start with `gemini.md` in the project root. It holds the role, the fidelity policy
and tool usage, and indexes the three rule files:

| File | What it holds |
|---|---|
| `style.md` | House style: prose, notation, environments, figures, provenance conventions |
| `build-and-preamble.md` | Build traps, `main.tex` facts and line numbers, numbering, the environment set |
| `project-state.md` | Blueprint tutor, what is done, document skeleton, standing decisions |

Read `gemini.md` plus whichever file covers the task at hand. New rules go in the
file matching their lifetime — that separation is deliberate.
